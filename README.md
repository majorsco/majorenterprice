# MajorEnterPrice website starter

## Pages
- `index.html` — homepage
- `about.html` — parent-company story
- `ventures.html` — venture overview
- `tech-services.html` — technology services
- `marketplace.html` — marketplace concept
- `investments.html` — investment concept
- `contact.html` — contact page

## Structure
```
majorenterprice/
├── index.html … contact.html
├── css/style.css
├── js/main.js
└── assets/images/   (logo, favicon)
```

## Open on your Mac
1. Download and unzip this folder.
2. Open VS Code, choose **File → Open Folder…**, and select `majorenterprice`.
3. Open `index.html`. For live preview, install the **Live Server** extension, right-click `index.html`, and choose **Open with Live Server**.
4. The official logo lives in `assets/images/logo.png` (transparent, white). To swap it, replace that file keeping the same name.

The site uses plain HTML, CSS, and JavaScript. Marketplace and investment pages are concept pages; the contact form is a front-end demo and is not connected to a backend. Before launching financial or payment features, arrange appropriate technical, legal, and regulatory setup.
